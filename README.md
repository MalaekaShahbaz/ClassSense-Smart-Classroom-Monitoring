# ClassSense Smart Classroom Monitoring
ClassSense is a smart classroom monitoring system that uses a Raspberry Pi and DHT11 sensor to measure temperature and humidity, store the data, and help monitor classroom environmental conditions.

# The aim is to collect, store and display environmental data so classroom conditions can be monitored over time.
